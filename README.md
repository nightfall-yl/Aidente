# Aidente

> 英文版见 [README_en.md](README_en.md)。

Aidente 是一款面向 Apple Silicon MacBook 的独立开源 macOS 菜单栏应用。它监测电池与供电数据，并可在用户明确授权的特权后台服务辅助下管理底层充电控制。

6.0.1 起支持从官方 GitHub Releases 页面安全地进行后台更新：启动后以及此后每六小时检查稳定版，校验 GitHub 提供的 SHA-256 摘要、应用签名、bundle 标识、版本与 arm64 架构，再通过具备回滚能力的后台服务替换已安装的应用。

本项目不包含 AlDente Pro 的代码、素材、激活逻辑或修改过的二进制文件。相关电池养护流程依据公开的行为描述与 GPL 兼容的开源基础独立实现。

## 版本 6.1.5（Build 26）

自 6.1（不含）以来完全落地的更新纲要：

**材质与外观**

- 材质收敛到单一绘制入口，跟随系统外观与「降低透明度」，移除 App 内材质覆盖开关。
- 仪表盘卡片透出窗口 L0 玻璃，浅色彩色前景用加深 ink 保证可读性。

**仪表盘**

- 弃用 `NSPopover`，改为无边框 `NSPanel`，外部点击可靠关闭。
- 支持长按编辑：隐藏卡片、整卡拖动排序，底部 dock 收纳未打开卡片。
- 状态栏电池图标按 macOS 15 单色 template 重绘，修复双屏非活跃屏幕不变淡。

**设置页**

- 重构为系统设置风格的左右分栏窗口：左栏玻璃、右栏实色，无标题栏。
- 「权限管理」改为「睡眠管理」，控制服务启动自动检测、一键重新授权。
- 页头固定为纯标题、可拖动窗口，新增带历史栈的前进 / 后退按钮。
- 浅色专用配色，界面文案补齐中英双语。

**工程**

- 应用图标按 macOS 模板重制；修复 Swift 6.2.4 + macOS 15.x SDK 的 `@Observable` 宏构建问题。

充电策略核心无变化。详见 [6.1.5 发行说明](BuildSupport/release-notes-6.1.5.md)。

## 版本 6.1（Build 21）

菜单栏电池为横向、自左向右填充。深色数字与充电标记在状态色电量区与淡灰蓝空电量区之间保持同色。无数字时项目宽 20pt，数字内置时宽 26pt（两侧各含 1pt 内边距）；电量 + 功率组合显示仍按实际瓦数文字自适应宽度。浅色 / 深色渲染覆盖空电量、半满、满电、低电量模式、禁用态配色与三位数瓦数。

- 固件保持使用未取整的硬件容量，写入整百分比边界时只向上取整一次。修复了旧「向下取整边界」上方的小数容量在插电时把 MacBook 切到电池供电的问题；新降低目标后的保持不会主动向目标放电，正常充电仍在设定上限停止。
- 两个保持端点在轮询与上限编辑之间保持固定，直到恢复充电或断开电源；清醒与睡眠保持分开存储，临时的睡眠边界不会替换清醒区间。
- 暂停充电以三次新鲜功率采样确认，并每 8 秒复查；持续的充电 / 放电会报告控制失败，仅寄存器写入被接受不再视为保持成功。
- 固件区间诊断包含原始容量、生效端点、激活与睡眠状态；显式放电仍是独立的用户操作。

在受影响机器上的短期观察显示：适配器供电期间电池功率为零，含上限变更与睡眠 / 唤醒切换；持续睡眠、完整充满循环与其它固件未验证。详见 [6.1 发行说明](BuildSupport/release-notes-6.1.md)。

## 系统要求

- Apple Silicon MacBook
- macOS 14 或更高版本
- 使用充电控制功能需要管理员授权

不安装特权后台服务也可使用监测功能。不受支持的控制项会被停用，而不是强制执行。

## 功能

- 可设定的充电上限
- 巡航区间，减少频繁微量补电
- 自动放电或一次性放电
- 补电至 100%
- 可断点续行的多阶段电池校准：
  - 充至 100%
  - 放电到设定的低电量
  - 再充至 100%
  - 满电保持
  - 恢复原充电上限
- 高温保护，带五分钟迟滞
- 硬件电量与 macOS 电量
- 按满充容量与设计容量估算、精确到一位小数的电池健康度
- 以 mAh 显示设计容量、当前容量与估算满充容量
- 自首次运行起长期记录容量历史，每天一个数据点
- 容量历史图表支持 30 天、一年与全部时间范围
- 电池健康、循环次数、温度、电压、电流与功率
- 功率分配图
- 功率分配图节点内实时显示适配器与电池的电压 / 电流
- 充电上限卡片内紧凑显示当前充电器协议 / 电压 / 电流 / 功率
- 仪表盘可直接开关高温保护、睡眠时暂停充电与巡航
- 受支持机型上的 MagSafe 指示灯状态
- 睡眠时暂停充电
- 可选：退出 Aidente 后保持充电状态
- 达到充电上限前阻止睡眠
- 按计划执行充电上限、补电、校准、暂停与放电任务
- 登录时启动，以及可自定义的菜单栏 / 仪表盘显示
- 跟随系统语言，并可即时切换中文 / 英文
- 可选的液态玻璃外观：在 macOS 26/27 上适配系统材质，在更旧的 macOS 上回退为兼容的半透明效果
- 从 macOS 应用元数据读取当前耗电 App 名称，兼容 Unicode
- 兼容 Apple 快捷指令的 URL 操作
- 可选开启的问题记录，附带可复制的支持 ID
- 一键在本地生成诊断 ZIP，自动做隐私脱敏
- 可选的崩溃报告收集，以及需单独同意才包含的耗电 App 名称
- 按需使用的内置 CLI，不额外常驻进程
- 隐藏菜单栏图标后，重新打开 app 时显示独立仪表盘窗口
- 对官方 GitHub Releases 稳定版进行自动与手动更新检查
- 一键后台下载、校验、安装并重启应用
- 替换或重启失败时回滚到上一个应用版本

## 安装

从 6.0 升级的用户需要手动安装一次 6.0.1，因为 6.0 尚未内置更新器；6.0.1 之后可在 Aidente 内完成更新。

把 `Aidente.app` 拖入 `/Applications`，打开后在 设置 → 充电管理 中开启「管理充电」，再完成管理员授权安装。以后升级或替换应用时，若已开启「管理充电」，Aidente 会在启动时自动提示重新授权，点击「立即重新授权」并通过 macOS 管理员弹窗完成即可。

本地分发包为 ad-hoc 签名，未经 Apple 公证。若首次启动被 Finder 拦截，右键点击应用并选择「打开」。

## 快捷指令 URL

在「快捷指令」中使用「打开 URL」操作，传入以下之一：

```text
aidente://set-limit?value=80
aidente://top-up
aidente://calibrate
aidente://pause
aidente://discharge?value=70
aidente://resume
```

## 诊断与命令行工具

打开 设置 → 诊断，可开始问题记录会话或导出诊断 ZIP。默认包不含耗电 App 名称，也不会收集账户名、序列号或网络配置。

可选的命令行工具位于：

```text
/Applications/Aidente.app/Contents/Resources/aidente
```

它可以查看状态，或触发与图形界面相同的 URL 操作：

```text
aidente status
aidente limit 80
aidente pause
aidente resume
aidente dashboard
aidente diagnostics
```

## 从源码构建

仓库内附有其开源依赖的固定副本，无需联网下载包即可构建：

```text
chmod +x BuildSupport/build_app.sh
BuildSupport/build_app.sh
```

产物为 `Dist/Aidente.app`。

构建后运行 `zsh BuildSupport/test_charging.sh`，可在不依赖硬件的情况下执行充电策略与有序写入的回归测试。用 `Dist/Aidente.app/Contents/MacOS/Aidente --render-status-icons=/tmp/Aidente-icons.png` 以 3 倍尺寸渲染生产状态栏图标。

## 安全说明与卸载

卸载前，请在 设置 → 充电管理 中关闭「管理充电」。这会注销特权后台服务，并恢复默认的充电、适配器与 MagSafe 指示灯状态。

底层 SMC 控制属于私有接口，未来的 macOS 版本可能变更。请自行承担使用风险，校准过程中保持充电器连接。
