# Aidente 6.1.3 · Build 24

本版把设置窗口重做为 macOS 系统设置风格：左侧分类侧栏 + 右侧详情，新增独立的「权限管理」页；随后对七个设置页做了全面审查整改（功能补齐、配色重排、本地化修复），并精简仪表盘、修复杂项。充电策略与底层服务逻辑没有改动（仅计划任务新增「恢复充电」动作）。

## 更新内容

### 设置窗口重构与视觉

- **设置页重构**：由顶部分段 Picker 改为 236pt 左侧栏 + 右侧详情，共 7 个分类（通用 / 仪表盘 / 充电管理 / 权限管理 / 计划与自动化 / 诊断 / 关于），选中项为系统蓝。「访问仪表盘」移到仪表盘 tab 末尾，「快捷操作」移到充电管理 tab 末尾；每个分类新增一行中英双语说明。
- **窗口层级与滚动**：标题栏补上 1pt 贯穿分隔线，并加一层独立的 chrome 遮罩，滚动时卡片在标题栏下方被截断，与原型一致；详情区标题与卡片一起滚动，左侧栏保持固定。
- **左右头部中心线对齐**：侧栏 App 图标与详情页徽章（各 34pt）几何中心强制落在同一水平线上（共享固定内容高度 46pt），不再受标题+副标题文字列高度影响；7 个导航项整行区域都可点击，「通用」首项与右侧第一张卡片上边距对齐，左侧主徽章改为运行中的应用图标。
- **配色三原则**：侧栏 7 个 tab 与每页首卡使用各不相同的身份色（新增「权限管理」蓝紫 `permissionColors`，诊断改靛紫，消除与通用/仪表盘撞色）；第二张卡起卡色跟功能语义（高温珊瑚警示、睡眠靛、通知橙等）；**相邻卡不得同色**，卡内提示与按钮颜色同步对齐。
- **侧栏语言选项**：中文界面下「English」显示为「英语」，英文界面仍为 English。
- **回退**：本版不含试验性的标题栏加高（28→38pt）与分段控件紧凑靠右两处改动，均已回退。

### 各页功能整改

- **新增「权限管理」页**：把原先散在充电管理里的授权提示与重新授权入口集中到这里。「重新检查授权」改为真正有用的「检查后台服务状态」——点击后显示后台服务是否已安装、身份是否与当前 Aidente 匹配，并引导重新授权；授权过程禁用按钮并显示状态，完成后状态卡自动转绿，无需手动复查。
- **计划与自动化**：新增「恢复充电」计划动作（与快捷指令 `aidente://resume` 对齐）；放电目标滑杆限 20–80%（不再与充电上限共用 20–100），切换动作自动纠偏；首次执行时间只能选未来（过去时间配合「错过后尽快补做」会立即触发）；快捷指令卡逐条附中文说明；任务行日期格式跟随界面语言，开关移至行尾。
- **通用 / 充电管理**：「使用硬件电量百分比」迁到充电管理页独立的「电量读取方式」卡（它影响所有充电策略，不属于菜单栏显示偏好）；充电上限滑杆范围 50–100 放宽到 20–100，与计划任务一致，低于 50% 的调度任务不再被滑杆静默改写；「睡眠与退出行为」三个开关按设备能力禁用置灰；通知总开关禁用时子开关说明改显原因。
- **诊断**：复制编号、复制 CLI 路径、停止记录、导出完成的反馈统一移到页面底部显示，不再出现在错误的卡片里；错误提示改用珊瑚警示色。
- **关于**：删除无实质内容的品牌 Hero 卡，剩「软件更新 + 法律与开源」两卡；法律三段标题修复英文漏翻；新增「查看第三方声明」按钮（打开内置 THIRD_PARTY_NOTICES.md）；「软件更新」卡去掉闲置时的「等待检查更新」占位面板，点「检查更新」后才显示进度与结果。
- **仪表盘精简**：设置页-仪表盘移除「实时功率」整张卡（电源来源 / 电池功率数据 / 适配器功率数据）；弹窗「彩色能量流」卡片同步去掉标题右侧电源来源与底部两行电气读数，只保留标题、功率分流图和充电器显示名。
- **文案与命名**：修订登录时启动、菜单栏实时读数、高温保护等说明；hero 状态「正在充电」改名为「充电中」，与 header 的硬件供电状态「正在充电」区分开；修复「自动检查更新」副标题在英文界面显示中文的问题（词典词条缺句号导致匹配失败）。

## 安装与升级

适用于 Apple Silicon MacBook、macOS 14 及以上。下载 DMG 后将 Aidente.app 拖入「应用程序」；6.0.1 及以上也可通过应用内检查更新安装。从 6.0 升级仍需先手动安装一次 6.0.1。

升级后若已开启「管理充电」，Aidente 会在启动时自动提示重新授权，通过 macOS 管理员弹窗更新应用及后台服务的身份登记。管理员密码只由系统弹窗接收。发行包沿用 ad-hoc 完整性签名，未经 Apple 公证；首次打开可按 macOS 提示从 Finder 右键选择「打开」。

本版目前只有本地构建产物 `Dist/Aidente-6.1.3.dmg`（3.7M，卷名 `Aidente 6.1.3`）。尚未发布 GitHub Release，因此没有官方的 `Aidente-6.1.3-arm64.dmg`、macOS ZIP 与 `SHA256SUMS-6.1.3.txt`。

## 验证范围

`zsh BuildSupport/build_app.sh` 完整构建 Exit 0，`codesign` 报 `valid on disk` / `satisfies its Designated Requirement`；`zsh BuildSupport/make_dmg.sh` Exit 0，输出 `Dist/Aidente-6.1.3.dmg`，`hdiutil verify` 结果为 VALID。bundle 内 `Info.plist` 为 6.1.3 / 24。构建日志现仅剩第三方 `Vendor/Defaults` 中 `onChange(of:perform:)` 在 macOS 14 已弃用的警告；`Aidente/` 下零警告。

`zsh BuildSupport/test_charging.sh` **138 项充电、睡眠、固件、回滚与读回检查全部通过**（脚本 SDK 选择已与构建脚本对齐：动态 `xcrun` 优先、15.5 兜底，修复了此前回归无法编译的问题）。

本版改动集中在设置窗口、仪表盘显示与计划任务入口，仍需在实机逐项核对：标题栏遮罩的滚动截断、左右头部对齐、设置页各处配色与文案（含英文界面）、计划任务「恢复充电」的实际执行、充电器显示名。未改动充电策略主体，充电、持续合盖睡眠与唤醒后的供电行为未因本版重新做硬件回归；macOS 26+ 的系统液态玻璃分支与「26+ 不叠自绘层」的表现仍需在 26 环境实机核对。
