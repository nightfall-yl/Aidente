# Aidente 6.1.1 · Build 22

本版把界面材质与外观收敛为单一策略，去掉菜单栏弹窗顶部的系统箭头，补齐面板显示开关与外观模式，并按 Apple 模板重制应用图标。设置窗口与充电控制逻辑没有改动。

## 更新内容

- 材质改由 macOS 决定，app 只保证文字可读性，不再提供多档材质选择器。色阶固定为亮 `#F4F5F6 / #F8F8F8 / #FCFCFC`、暗 `#232326 / #28282B / #2D2D31`，层级差值恒定；卡片只留 1pt 中性描边，去掉阴影。旧的材质偏好会一次性迁移为「始终使用不透明背景」。
- macOS 26 以前的系统，仪表盘使用类液态玻璃材质：在 `NSVisualEffectView` 之上叠加自绘的边缘增厚、tint、内缩柔光、顶部高光与 1pt 角向渐变描边。升级到 macOS 26+ 后自动改用系统液态玻璃材质，且不再叠加自绘层。系统开启「降低透明度」或 app 开启「始终使用不透明背景」时回退为实体底色；设置窗口是标准标题栏窗口，始终使用实体底色。
- 「外观」卡片新增 自动 / 浅色 / 深色 分段控件，全局生效；界面不再强制暗色，浅色外观补齐页眉、卡片与工具栏的配色。删除设置页「高级」标签页，原功能并入「通用」。
- 弃用 `NSPopover`，主菜单改为无边框、透明背景、圆角 15 的浮动 `NSPanel`，系统强加的顶部箭头彻底消失。面板锚定在状态栏图标正下方，随内容高度向下生长；外部点击与再次点击图标都能可靠关闭，并修复快速连点导致面板不渲染或位置漂移。
- 仪表盘新增四个功能卡片显示开关（容量与寿命趋势、当前耗电 App、快捷养护、自动保护），默认全部开启，隐藏后面板高度自动收缩。此前这些开关只被一段零引用的旧菜单代码消费，实际面板并没有读取。
- 状态栏电池图标按 macOS 15 单色 template 风格重绘：透明内部、`.primary` 描边与填充、右端凸起、反色的数字与充电标记。同时修复双屏时非活跃屏幕的菜单栏图标不变淡，以及反复重建后 Finder 中 `.app` 图标缩略图陈旧的问题。
- 修复功率流图导线左右溢出与箭头未对齐；header 的「系统运行时间」「电池剩余时间」上移为 10 pt 灰色小字，右上角刷新 / 设置 / 退出按钮统一为 `.secondary` 灰字；仪表盘宽度 408 → 400、高度上限 720 → 800（超过滚动，不足取实际值）。「温度」改名为「电池温度」，设置页「状态信息」卡重排，并删除原「剩余使用时间」开关。
- 应用图标按 Apple macOS 模板重制：1024×1024 画布中把主体收进 824×824 居中框、四边各留 100pt，各档均从 2048px 超采样主图下采样，补齐此前缺失的 `ic10` 1024×1024 档。同一口径下可见边界由约 95.3% 收敛到 87.7%，解决启动台里图标比其它 App「大一圈」的观感。
- 构建脚本改为用 `xcrun --sdk macosx --show-sdk-path` 动态解析 SDK，修复 Swift 6.2.4 搭配 macOS 15.x SDK 时 `@Observable` 宏展开失败导致的首次编译报错，部署目标仍为 macOS 14.0。另外清掉 `AidenteTheme.swift` 中两条 main actor 隔离警告，统一「外观」卡片副标题文案，并同步三份 HTML 设计原型与 6.1.1 现状。

## 安装与升级

适用于 Apple Silicon MacBook、macOS 14 及以上。下载 DMG 后将 Aidente.app 拖入「应用程序」；6.0.1 及以上也可通过应用内检查更新安装。从 6.0 升级仍需先手动安装一次 6.0.1。

升级后如需管理充电，可在应用中点击「修复控制服务」，通过 macOS 管理员授权更新应用及后台服务的身份登记。管理员密码只由系统弹窗接收。发行包沿用 ad-hoc 完整性签名，未经 Apple 公证；首次打开可按 macOS 提示从 Finder 右键选择「打开」。

本版目前只有本地构建产物 `Dist/Aidente-6.1.1.dmg`（卷名 `Aidente 6.1.1 (build 22)`）。尚未发布 GitHub Release，因此没有官方的 `Aidente-6.1.1-arm64.dmg`、macOS ZIP 与 `SHA256SUMS-6.1.1.txt`。

## 验证范围

`zsh BuildSupport/build_app.sh` 完整构建 Exit 0，`codesign --verify --deep --strict` 通过，`nm` 已确认类液态玻璃相关符号进入可执行文件；`zsh BuildSupport/make_dmg.sh` 输出 `Dist/Aidente-6.1.1.dmg`，`hdiutil verify` 结果为 VALID。bundle 内 `Info.plist` 为 6.1.1 / 22，`Aidente.icns` 与 `BuildSupport/Aidente.icns` 一致（702747 字节）。构建日志现仅剩第三方 `Vendor/Defaults` 中 `onChange(of:perform:)` 在 macOS 14 已弃用的警告；本轮修掉的两条 `main actor-isolated` 警告已归零。

图标按同一 alpha 边界口径对比了新旧主体占比，并检查了各档尺寸、方向、投影与按钮图形；三份 HTML 原型做过结构、标签配对与内联 JS 校验，它们不参与构建。

类型检查与打包通过不能代替实机验收。当前实机 15.8.2 可验收仪表盘的毛玻璃与自绘光效、设置页 / 仪表盘层级以及「始终使用不透明背景」开关；macOS 26+ 的系统液态玻璃分支、「26+ 不叠自绘层」的表现，以及设置页固定实体色与仪表盘玻璃的观感一致性，仍需在 26 环境实机核对。本版没有改动充电策略，充电、持续合盖睡眠与唤醒后的供电行为未因本版重新做硬件回归。
