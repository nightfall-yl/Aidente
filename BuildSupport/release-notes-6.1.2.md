# Aidente 6.1.2 · Build 23

本版重构仪表盘的交互组织方式：卡片改为仿 macOS 小组件的「长按进入编辑态」，用底部 dock 管理显隐、用整卡拖动重排顺序；同时把历史里残留的「主菜单」措辞统一为「仪表盘」，并微调设置页-仪表盘的结构与文案。充电控制与底层服务逻辑没有改动。

## 更新内容

- 仪表盘卡片支持长按编辑：整张卡片任意位置长按 0.5 秒进入编辑态；已显示卡片左上角出现红色减号，点按即移回 dock；底部 dock 以实色蓝「图标 + 名称」胶囊只列出未打开的卡片，点按即打开并即时从 dock 消失，dock 为空时整个胶囊区不渲染、不留占位。编辑态底部保留「长按进入编辑模式」提示与「已完成」按钮。
- 六张可编辑卡片在编辑态下任意位置按住即可拖动重排，无专属拖拽 icon；顺序持久化到 `dashboardCardOrder`（逗号分隔），已存偏好里缺失的卡按默认位置插入，不会被追加到末尾。常驻卡只有「状态信息」hero（含充电上限滑杆），不进入编辑态。
- 底部悬停引导 + hover 渐变带：仪表盘底部 20pt 悬停热区，鼠标悬停时才显示「长按进入编辑模式」以及一条跟随出现的渐变带（正常态完全透明），渐变带与文字一同 0.15s 淡入、一同消失；该热区也支持长按进入，保证卡片全部移出后仍能回到编辑态。
- 「电池健康」与「彩色能量流」纳入编辑体系：两卡均可长按编辑 / 拖动排序 / 进 dock。「电池健康」由 `showBatteryHealthCard` 控制整张指标条显隐，指标条三项（电池健康 / 循环次数 / 电池温度）恒显示；「彩色能量流」显隐复用 `showPowerDistribution`，卡片标题与 dock 一致为「彩色能量流 / Color Energy Flow」。
- dock 横向滚动与实色蓝胶囊：胶囊保持「图标 + 完整标题」，不压缩、不截断；剩余胶囊不足以撑满面板时整行水平居中，超出时左对齐并向右横滑，46pt 行内垂直居中。胶囊为实色 `AidenteTheme.ocean`（`0.24, 0.56, 0.98`）配白色文字与图标，8pt 圆角。
- 设置页-仪表盘重排：长按编辑成为卡片显隐的唯一入口，设置页不提供模块开关；页面为 访问仪表盘 → 状态信息 → 实时功率 三张卡。「访问仪表盘」卡片组（含说明与「打开仪表盘」按钮，打开 `aidente://dashboard`）位于仪表盘 tab 第一个，「电源来源」开关位于「实时功率」组第一个。
- 仪表盘命名统一：设置页卡片为「访问仪表盘」、按钮「打开仪表盘」，说明文案为「完整仪表盘 / 独立仪表盘窗口」，与英文词条语义一致。CLI 帮助与输出、独立窗口标题（`Aidente Dashboard`）、两张 HTML 原型、`README.md` 均使用仪表盘语义，无「主菜单」旧称；中文文案与字典 key 成对维护，英文模式不会退回中文原文。
- 「状态信息」卡副标题收窄为「选择仪表盘顶部显示的系统与电池时间信息。」，仅控制 header 两行时间（系统运行时间 / 电池剩余时间）。

## 安装与升级

适用于 Apple Silicon MacBook、macOS 14 及以上。下载 DMG 后将 Aidente.app 拖入「应用程序」；6.0.1 及以上也可通过应用内检查更新安装。从 6.0 升级仍需先手动安装一次 6.0.1。

升级后如需管理充电，可在应用中点击「修复控制服务」，通过 macOS 管理员授权更新应用及后台服务的身份登记。管理员密码只由系统弹窗接收。发行包沿用 ad-hoc 完整性签名，未经 Apple 公证；首次打开可按 macOS 提示从 Finder 右键选择「打开」。

本版目前只有本地构建产物 `Dist/Aidente-6.1.2.dmg`（卷名 `Aidente 6.1.2 (build 23)`）。尚未发布 GitHub Release，因此没有官方的 `Aidente-6.1.2-arm64.dmg`、macOS ZIP 与 `SHA256SUMS-6.1.2.txt`。

## 验证范围

`zsh BuildSupport/build_app.sh` 完整构建 Exit 0，`codesign --verify --deep --strict` 通过；`zsh BuildSupport/make_dmg.sh` 输出 `Dist/Aidente-6.1.2.dmg`，`hdiutil verify` 结果为 VALID。bundle 内 `Info.plist` 为 6.1.2 / 23，主二进制约 7.8M，`Aidente.icns` 与 `BuildSupport/Aidente.icns` 一致。构建日志现仅剩第三方 `Vendor/Defaults` 中 `onChange(of:perform:)` 在 macOS 14 已弃用的警告；`Aidente/` 下零警告。

本机（macOS 15.8.2）已实机验收全部改动：`highPriorityGesture` 未吞掉卡片内 Picker / 养护 / 保护按钮短按；「访问仪表盘」可打开独立窗口；六枚 dock 胶囊横滑、实色 `ocean` 配白字在深浅色下对比度与辨识度正常；「彩色能量流」移出后可从 dock 恢复且面板高度/滚动正常；编辑态整卡拖动落点与减号点击有效；hover 渐变带淡入淡出与 2pt↔11pt 切换面板高度无跳动；dock 仅剩 1–2 枚时居中、点掉一枚居中↔滚动切换无跳动或裁切；「已完成」padding 10pt 点击区够用；「状态信息」新副标题中英译文正确；dock 胶囊上下留白对称、与提示文字间距自然；六张非常驻卡任意位置（含标题行空白）长按均进编辑态、边缘 2pt 不触发、容量卡 Picker 区域长按有效、Button/Picker 短按未被 contentShape 吞掉、实色蓝胶囊配白字可读性达标。

本版没有改动充电策略，充电、持续合盖睡眠与唤醒后的供电行为未因本版重新做硬件回归；macOS 26+ 的系统液态玻璃分支与「26+ 不叠自绘层」的表现仍需在 26 环境实机核对。
