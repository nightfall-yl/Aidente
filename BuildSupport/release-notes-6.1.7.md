# Aidente 6.1.7 · Build 28

## 更新内容

### 仪表盘

- **popover 顶部整合**：取消 header 区块，常态状态标题并入 hero 卡内并与异常横幅统一信息源（`operationStatusTitle`）、二者互斥；电源信息单行迁入「规格」卡上半（适配器供电 = 适配器名 + V@A，电池供电 = 「电池供电」+ 电池 V@A），下半健康度 / 循环数 / 温度三格不变；右上角刷新按钮移除（面板打开时已每秒自动轮询，冗余），剩设置 / 退出两枚。
- **功率桑基图重绘与动效**：流管改为粗渐变三层绘制——无色底管常驻、彩色三色渐变「信息层」常驻、白色光带「动效层」沿流管平移（柔光 + 亮芯，扫描 2.5s + 出框停顿 1.5s = 周期 4s，透明度深浅色分主题）；流管转角 5pt 圆角、全高节点 120pt、分流态上下节点按功率贡献分配高度；动效按屏幕刷新率渲染；新增「流动光效」开关（默认开，置于「控制面板」卡首行），关闭后只保留彩色信息层、暂停动画时间线省开销；系统「减弱动态效果」同样只保留信息层。
- **hero 收敛**：徽章 34pt、实时电量与上限百分比统一 18pt；状态行仅在异常或临时动作生效中显示，常态由卡内标题行承担；「修复中…」短暂态去除，文案恒为「充电控制未生效 / 点击修复充电控制」；滑杆手柄左侧显示巡航下限虚线（随上限拖动实时移动）。
- **编辑态高度动画与底部间隔带**：进入/退出编辑态的面板高度动画由单一进度数据源逐帧驱动（120Hz、0.18s easeInOutQuad），面板原子顶部锚定 resize，修复退出编辑态的卡片弹跳；卡片下边距 2pt → 11pt 与顶部对称，常态 18pt hover 条取消（面板总高省约 16pt）；「长按进入编辑模式。」提示移入间隔带（上距卡片 0.5pt、下距面板底边 0.5pt），hover 显隐（ocean 渐变面色 + 发丝线，热区 = 11pt 间隔带、左右铺满面板宽度）；编辑栏进入渐显、退出随高度收回渐隐。
- **卡片**：默认顺序与命名定为 功率桑基图 / 规格 / 高能耗应用 / 电池健康；三格读数标签为 健康度 / 循环数 / 温度；「自动保护」卡删除（设置页已有同族开关）；面板宽度 370。
- **「高能耗应用」精简**：单一达标 App（图标 + 名称 + CPU 百分比 + 进度条）。判定：`%cpu ≥ 25%` 且为第二名 1.5 倍、连续 2 次采样才显示，低于 12% 连续 3 次才撤下；无达标项显示「当前无高功耗应用」。

### 捷径卡

- **新增「恢复正常模式」**：电池供电且系统低电量模式开启时，一键临时关闭低电量模式，接通电源自动恢复原设置（经 root 助手 `pmset -b lowpowermode 0`，仅写电池电源配置）。hero 横幅联动；**需升级安装后台助手（新增 `setLowPowerMode` XPC）**。
- **「放电至充电上限」下线**：与设置页「启用自动放电」重合；底层放电机制保留，自动化任务的「放电至指定电量」不受影响。

### 更新体验

- **更新成功提示提速**：更新后启动改为自适应轮询 daemon 重 pin（原为固定等待链），「更新成功」弹窗从约 3 秒缩短到约 2 秒，并跟随 daemon 实际节奏；轮询窗口保持 4 秒以上，慢机器不会误弹重新授权。

### 修复

- **高能耗应用卡中文乱码**：进程采样 `ps` 由 `LC_ALL=C` 改 `en_US.UTF-8`，中文应用名不再显示为 `M-x` 转义乱码；命令路径兜底增加存在性校验。
- **限充误报宽限**：充电中切回限充保持时给固件停充滞后约 32 秒宽限，消除「充电控制未生效（已请求暂停，但电池仍持续充电）」的短暂误报。
- **文案**：「电源信息」卡无副标题；「容量与寿命趋势」「当前耗电 App」等旧卡名词条随更名清理。

### 工程清理（行为无变化）

- 删除菜单时代遗留死代码：`MenuViewModel` 7 个只写不读属性与系统运行时间刷新链、零引用历史协议 `HelperProtocol` / `ChargingHelperProtocol`、`SMCBattery.firmwarePercentage()` 整数版、`AidenteControlProtocol` 的 `resetToDefaults()` 声明与实现（卸载恢复用的 `restoreDefaults` 保留实现）；遗留 `Localizable.xcstrings` 归档至 `Archive/`。充电回归 134 项全过。

充电策略核心无变化。

## 安装与升级

适用于 Apple Silicon MacBook、macOS 14 及以上。下载 DMG 后将 Aidente.app 拖入「应用程序」；6.1.5 及以上也可通过应用内检查更新安装（更新源为 `nightfall-yl/Aidente` 的 GitHub Release），升级全程免重新授权。

## 验证范围

`zsh BuildSupport/build_app.sh` 完整构建 Exit 0，`codesign` 报 `valid on disk` / `satisfies its Designated Requirement`；`zsh BuildSupport/test_charging.sh` 134 项充电 / 睡眠 / 固件 / 回滚 / 回读检查通过（本轮无充电策略改动，回归为纯逻辑确认）；`zsh BuildSupport/make_dmg.sh` Exit 0，输出 `Dist/Aidente-6.1.7.dmg`，`hdiutil verify` 结果为 VALID。bundle 内 `Info.plist` 为 **6.1.7 / 28**。
