# Aidente 6.1.7 · Build 28

## 更新内容

### 设置页与界面

- **删除「仪表盘」设置 tab**：设置页由 7 项缩为 通用 / 充电管理 / 睡眠行为 / 自动化 / 诊断 / 关于 6 项；原「访问仪表盘」卡改挂到「通用」页最后，保持 headless 形态（标题行 + 副标题 +「打开仪表盘」按钮），`aidente://dashboard` 仍可从设置页打开独立窗口。
- **导航与首卡配色**：充电管理改为绿色（`chargingColors`）、睡眠行为改为紫色（`dashboardColors`），通用蓝 / 自动化橙 / 诊断橙红 / 关于蓝紫不变；各页首卡与 tab 同色，「电池巡航」卡徽章改用通用蓝。
- **设置页专用徽章**：侧栏 App 徽章不再复用 `Aidente.icns`（外圈玻璃高光缩到 34pt 后四角出现白边），改用独立资源 `BuildSupport/SettingsBadge.png`——去掉玻璃外圈与内发光，深色底板满幅 34pt，电池组以中心缩至 75%，小尺寸下四角干净、电池不再撑满底板。

### 仪表盘

- **卡片更名与默认顺序**：「能量分流」→「功率桑基图」，6.1.6 的「电池健康」状态卡→「规格」，「容量与寿命趋势」→「电池健康」，「快捷养护」→「捷径」。默认顺序为 hero、规格、功率桑基图、高能耗应用、电池健康、捷径；「自动保护」卡删除。已保存自定义顺序的用户不受影响。
- **hero 卡**：取消顶部 header，常态状态标题并入卡内并与异常横幅统一信息源；「系统运行时间」「电池剩余时间」两行及对应开关、词典词条删除；设置 / 退出悬浮右上角，刷新按钮删除（面板已每秒轮询）；一键修复不再显示「修复中…」中间态；状态行仅在异常或临时动作生效中显示，常态由卡内标题行承担；滑杆手柄左侧新增巡航下限虚线（随上限拖动实时移动）；徽章 34pt、电量与上限百分比统一 18pt。
- **规格卡**：供电来源单行迁入上半（适配器供电 = 适配器名 + 适配器 V@A，电池供电 = 「电池供电」+ 电池 V@A），下半健康度 / 循环数 / 温度三格不变；三格标签改名为 健康度 / 循环数 / 温度；来源名与 V@A 为 11pt medium 次要色、等宽数字，分隔线与内容同宽。
- **功率桑基图**：粗渐变三层流管——无色底管常驻、彩色三色渐变「信息层」常驻、白色光带「动效层」沿流管平移（柔光 + 亮芯，扫描 2.5s + 出框停顿 1.5s = 周期 4s，透明度深浅色分主题）；动效按屏幕刷新率渲染，系统「减弱动态效果」时只保留信息层与底管；拐角 5pt 圆角、全高节点 120pt，右侧上下节点按功率贡献分配高度；节点徽章显示整数、管内保留两位小数。
- **高能耗应用**：精简为单一达标 App（图标 + 名称 + CPU 百分比 + 进度条，进度按 100% 单核心刻度）；判定 `%cpu ≥ 25%` 且为第二名 1.5 倍、连续 2 次采样（约 8 秒）才显示，低于 12% 连续 3 次撤下；无达标项显示占位文案。中文应用名乱码修复：`ps` 由 `LC_ALL=C` 改 `en_US.UTF-8`，命令路径兜底增加存在性校验。
- **捷径卡**：新增「恢复正常模式」——电池供电且低电量模式开启时一键临时关闭，接通电源自动恢复原设置，hero 横幅联动；**需升级安装后台助手（新增 `setLowPowerMode` XPC）**。「放电至充电上限」下线，与设置页「启用自动放电」重合，底层放电机制保留。
- **面板尺寸与交互**：面板宽 360pt，卡片左右距边缘 11pt、上下 12pt，卡片内文字左右边距统一 12pt，hero 圆角 14pt；编辑态高度动画由单一进度源逐帧驱动，底部 12pt 间隔带承载「长按进入编辑模式。」提示；独立仪表盘与设置页共存——从独立窗口点齿轮保留独立窗口，从菜单栏面板点则照旧关闭。

### 更新

- **更新成功提示提速**：更新后启动改为自适应轮询 daemon 重 pin（原为固定等待链），「更新成功」弹窗从约 3 秒缩短到约 2 秒，并跟随 daemon 实际节奏；轮询窗口保持 4 秒以上，慢机器不会误弹重新授权。
- **重新授权提示精简**：标题改为「重新授权后台控制服务」（更新分支为「Aidente 已更新至 X，需重新授权」），正文压缩为「主程序改变，后台控制服务登记身份不匹配，充电管理不可用。点击「立即重新授权」即可恢复。」；中英同步。

### 应用图标

- **最外圈玻璃边缘**：圆角底板采用外圈高光渐变描边 + 模糊内发光，无额外硬细线，主体、配色、比例不变；按 macOS 标准将主体置于 824×824 居中框（四边 100pt、主体占比约 80.5%），重新生成 10 档 `BuildSupport/Aidente.icns`。

### 修复

- **限充误报宽限**：充电中切回限充保持时给固件停充滞后约 32 秒宽限，消除「充电控制未生效（已请求暂停，但电池仍持续充电）」的短暂误报。

### 工程清理（行为无变化）

- 删除菜单时代遗留死代码：`MenuViewModel` 7 个只写不读属性与系统运行时间刷新链、零引用历史协议 `HelperProtocol` / `ChargingHelperProtocol`、`SMCBattery.firmwarePercentage()` 整数版、`AidenteControlProtocol` 的 `resetToDefaults()` 声明与实现（卸载恢复用的 `restoreDefaults` 保留实现）；遗留 `Localizable.xcstrings` 归档至 `Archive/`。充电回归 134 项全过。

充电策略核心无变化。

## 安装与升级

适用于 Apple Silicon MacBook、macOS 14 及以上。下载 DMG 后将 Aidente.app 拖入「应用程序」；6.1.5 及以上也可通过应用内检查更新安装（更新源为 `nightfall-yl/Aidente` 的 GitHub Release），升级全程免重新授权。
