# Aidente 6.1.7 · Build 28

## 更新内容

### 仪表盘

- **能量分流图重绘**：流管改为粗渐变三层绘制——无色底管常驻、彩色三色渐变「信息层」常驻、白色光带「动效层」沿流管平移（柔光 + 亮芯，扫描 2.6s + 出框停顿 0.4s = 周期 3s，光带透明度深浅色分主题）；全高节点 120pt，分流态上下节点按功率贡献分配高度、间隔 20pt；功率文字节点取整、流管保留两位小数。动效按屏幕刷新率渲染，告别低帧率卡顿；系统开启「减弱动态效果」时只保留信息层。
- **顶部信息区改义**：原「系统运行时间」「电池剩余时间」两行改为电源信息位（供电类型 / 电压电流），由「电源信息」卡两个开关控制；能量分流卡不再重复显示标题。
- **hero 卡度量收敛**：徽章 39 → 34pt，实时电量与上限百分比统一 18pt。
- **「当前耗电 App」精简**：三行榜单改为单一高功耗 App（图标 + 名称 + CPU 百分比 + 进度条）。判定：`%cpu ≥ 25%` 且为第二名 1.5 倍、连续 2 次采样才显示，低于 12% 连续 3 次才撤下；无达标项显示「当前无高功耗应用」。

### 更新体验

- **更新成功提示提速**：更新后启动改为自适应轮询 daemon 重 pin（原为固定等待链），「更新成功」弹窗从约 3 秒缩短到约 2 秒，并跟随 daemon 实际节奏；轮询窗口保持 4 秒以上，慢机器不会误弹重新授权。

### 修复与文案

- 「电源信息」卡（原「状态信息」）副标题改为「仪表盘菜单栏副标题。」，中英双语同步。

充电策略核心无变化。

## 安装与升级

适用于 Apple Silicon MacBook、macOS 14 及以上。下载 DMG 后将 Aidente.app 拖入「应用程序」；6.1.5 及以上也可通过应用内检查更新安装（更新源为 `nightfall-yl/Aidente` 的 GitHub Release），升级全程免重新授权。

## 验证范围

`zsh BuildSupport/build_app.sh` 完整构建 Exit 0，`codesign` 报 `valid on disk` / `satisfies its Designated Requirement`；`zsh BuildSupport/test_charging.sh` 134 项充电 / 睡眠 / 固件 / 回滚 / 回读检查通过（本轮无充电策略改动，回归为纯逻辑确认）；`zsh BuildSupport/make_dmg.sh` Exit 0，输出 `Dist/Aidente-6.1.7.dmg`，`hdiutil verify` 结果为 VALID。bundle 内 `Info.plist` 为 **6.1.7 / 28**。
