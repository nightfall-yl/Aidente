04

现行状态（6.1.5 / Build 26）

2026-11-16 已发行的落地结论，取代前三节中被推翻的部分

仪表盘卡片透出 L0 玻璃

  • 普通卡片与 hero 渐变半透明绘制，透出窗口已采样的系统材质；填充透明度浅色 0.3 / 深色 0.4（AidenteSurfaceTokens.dashboardCardAlpha）。
  • 系统开启「降低透明度」或容器无法采样背景时自动回到不透明；玻璃只在 L0 采一次，卡片只做半透明，不碰 .withinWindow、不做双重模糊。
  • 实验依据：dashboard-card-glass-prototype.html（alpha 单变量实验，拖滑块验证）。

L0 染色

  • glassTint 浅色完全透明（白色提亮会冲平桌面轮廓）、深色保留 rgb(30,30,34) 0.24 的磨砂感。AppKit .popover 自带染色。

浅色彩色前景加深

  • 五组 ink 色（coral / amber / jade / ocean / violet）+ legibleTextTint(_:scheme:)：浅色下仪表盘全部彩色文字与小图标映射到加深色，深色不变；进度条、渐变、徽章底、图例色块等装饰色仍用原色。

已删除的开关

  • 「始终使用不透明背景」及其 key、迁移、诊断字段已全链路删除（02 节文档中提到的该开关描述即此条的历史痕迹）；材质完全跟随系统「降低透明度」。

设置页配色（独立分支，不属玻璃族）

  • 浅色右栏底 #EDEEF0（detailPaneColor）、卡片专用 #F5F5F7（AidenteSurfaceTokens.settingsCardColor，经 aidenteUsesSettingsCardFill 环境开关，仅设置窗口生效）；全局 L2 token 与仪表盘、菜单卡片不变。
  • 设置页结构与控件的基线见 settings-prototype.html。

源码锚点

  • Aidente/Views/AidenteTheme.swift：AidenteSurfaceTokens（色阶 / tint / cardAlpha / settingsCardColor）、AidenteGlassOverlay（边缘增厚 / 内缩柔光 / 角向描边）、AidenteLevelSurface（唯一绘制入口）。
  • Aidente/Views/DashboardPopoverView.swift：heroCardFillAlpha（hero 渐变与普通卡共享同一 readability 门控 alpha）。
